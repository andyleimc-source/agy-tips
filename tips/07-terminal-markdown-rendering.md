# 07 · agy 终端 Markdown 渲染与排版避坑

> 环境：agy（Antigravity CLI）+ 现代终端（Ghostty / iTerm2 / WezTerm 等），macOS 实测 2026-08-14。

## 痛点

在终端使用 `agy` 交互时，经常看到模型输出一堆带井号的原始文本（如 `### 小标题`、`#### 子项目`），终端并没有像网页那样把它们渲染成标题，影响可读性。

## 为什么会这样

1. **`agy` 交互式 TUI 无法外挂渲染器**：`agy` 内部跑着自己的终端 UI 渲染引擎，无法直接把外部工具（如 `glow`、`mdcat`）挂接进交互会话的文本流中。
2. **内置解析器的限制**：`agy` 的 TUI 对加粗（`**`）、代码块（` ``` `）、有序/无序列表和顶层标题（`#` / `##`）支持良好，但遇到 3~4 级深层标题（`###` / `####`）时不会做字体放大或特殊着色，而是直接原样打出井号。

---

## 交互模式最佳方案：规则约束（用加粗列表替代多级标题）

最直接、效果最好的方式是在全局规则（`~/.claude/CLAUDE.md` / `GEMINI.md`）或提示词中约束输出格式：

```markdown
回复排版：不要使用 `###` 或 `####` 多级标题语法，统一改用「加粗小标题」与「列表」进行结构化组织。
```

对比效果：
* ❌ `#### 1. 核心问题` → 终端显示原样井号 `#### 1. 核心问题`
* ✅ **1. 核心问题** → 终端完美渲染加粗高亮，层级分明

---

## 衍生技巧：单次查询与文档查看的渲染方案

如果你不是在 `agy` 交互界面里聊天，而是 **单次 CLI 提问** 或 **查看 agy 生成的 `.md` 文档**，推荐搭配成熟的终端 Markdown 渲染器：

### 1. 工具选择

* **[glow](https://github.com/charmbracelet/glow)**（首选）：终端 Markdown 渲染标杆，支持 TrueColor、代码高亮、表格、翻页。
  ```bash
  brew install glow
  ```
* **[mdcat](https://github.com/swsnr/mdcat)**（有图时推荐）：Rust 开发，在 Ghostty / Kitty 等终端下能直接走 Kitty 协议渲染 Markdown 内嵌图片。
  ```bash
  brew install mdcat
  ```

### 2. 配置 Zsh 快捷别名

在 `~/.zshrc` 中加入：

```zsh
# 单次向 agy 提问并自动通过 glow 优美渲染
ask() {
  agy -p "$*" | glow
}

# 替代 cat/less 优美查看项目里的 markdown 文档
alias md="glow -p"
```
